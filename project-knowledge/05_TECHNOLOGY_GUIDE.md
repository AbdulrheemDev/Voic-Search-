## 1. Web Speech API (SpeechRecognition)
- **الدور:** تحويل كلام المستخدم العربي إلى نص في المتصفح (FR-01، FR-03، FR-13).
- **سبب الحاجة:** المشروع لا يبني نموذج تعرف (النطاق)؛ واجهة قياسية تدعم تحديد لغة التعرف.
- **يتصل بـ:** واجهة البحث (JavaScript) ← متحكم البحث في Laravel.
- **ما يجب فهمه:** الخصائص `lang` (BCP 47)، `continuous`، `interimResults`؛ الأحداث `result`، `error`، `speechend`، `end`؛ البدائل ودرجة الثقة؛ البادئة `webkitSpeechRecognition`؛ في Chrome يُرسل الصوت إلى خادم (يتطلب إنترنت)؛ ليست مدعومة في جميع المتصفحات.
- **متطلبات تشغيل تحتاج تحققًا:** Chrome حديث؛ اتصال إنترنت؛ إذن الميكروفون؛ الصفحة عبر HTTPS أو localhost (قيد شائع في المتصفحات لاستخدام الميكروفون **[يحتاج تحقق في بيئة الفريق]**)؛ رمز اللغة العربية المناسب (A-06).
- **التحقق من العمل:** زر الميكروفون يظهر في Chrome ويختفي في متصفح غير داعم؛ نطق «حقيبة ظهر» يعيد نصًا عربيًا في حدث result.
- **أخطاء شائعة:** رفض الإذن (`not-allowed`)؛ لا كلام (`no-speech`)؛ انقطاع الشبكة (`network`)؛ نسيان ضبط lang فيتعرف بالإنجليزية؛ اختبار الصفحة من file://.

## 2. HTML / CSS / JavaScript
- **الدور:** واجهة البحث، منطق زر الميكروفون، إرسال الطلب، عرض النتائج (IR-01).
- **سبب الحاجة:** لغات الويب المدعومة في جميع المتصفحات.
- **يتصل بـ:** Web Speech API، مسار API في Laravel.
- **ما يجب فهمه:** البرمجة بالأحداث؛ fetch/طلبات HTTP غير المتزامنة؛ معالجة JSON؛ اتجاه RTL في الواجهة.
- **التحقق:** أدوات المطور في Chrome (Console، Network).
- **أخطاء شائعة:** عدم معالجة الاستجابة الفارغة؛ عدم إظهار حالة الاستماع (NFR-04)؛ مشكلات CSRF عند POST في Laravel.

## 3. PHP / Laravel 12
- **الدور:** طبقة التطبيق: متحكم البحث، التطبيع، حذف عبارات الطلب، القاموس، خدمة البحث (القسم 1.5.3).
- **سبب الحاجة:** المتجر المستضيف مبني بـ Laravel؛ إطار متكامل يوفر التوجيه والنماذج وحزمة البحث.
- **يتصل بـ:** الواجهة (HTTP/JSON)، Laravel Scout، Eloquent/MySQL.
- **ما يجب فهمه:** Routing، Controllers، Service classes، Eloquent Models، Migrations، ملفات config و.env، Artisan.
- **متطلبات تحتاج تحققًا:** إصدار PHP المطلوب لـ Laravel 12 **[لم يحدده المصدر]**؛ Composer؛ توافق المتجر المستضيف مع Laravel 12 **[غير متحقق — قد يكون المتجر الجاهز بإصدار آخر، انظر R-01]**.
- **التحقق:** `php artisan route:list`؛ اختبار المسار يدويًا.
- **أخطاء شائعة:** أخطاء الترميز UTF-8 مع العربية؛ استخدام دوال نصية غير متعددة البايت (يجب `mb_*`).

## 4. Laravel Scout
- **الدور:** ربط نموذج المنتج بفهرس Meilisearch، المزامنة التلقائية (FR-08)، تنفيذ البحث واسترجاع النماذج بالترتيب، التقسيم إلى صفحات (FR-09، FR-10).
- **سبب الحاجة:** حزمة رسمية تحافظ على تزامن الفهرس وتدعم Meilisearch.
- **يتصل بـ:** نموذج المنتج (Searchable، toSearchableArray)، Meilisearch، Eloquent.
- **ما يجب فهمه:** trait Searchable؛ toSearchableArray؛ `scout:import`؛ إعداد index-settings في config/scout.php وأمر `scout:sync-index-settings`؛ متى تحدث المزامنة (أحداث النموذج) ومتى لا تحدث (تحديثات جماعية لا تمر بأحداث Eloquent **[يحتاج تحقق على المتجر الفعلي]**).
- **أخطاء شائعة:** الفهرس قديم بعد تعديل مباشر في قاعدة البيانات؛ نسيان تطبيع الحقول في toSearchableArray؛ تجاهل الطابور (queue) إن كان مفعّلًا.

## 5. Meilisearch
- **الدور:** فهرسة المنتجات والبحث والترتيب والتسامح مع الأخطاء والمرادفات.
- **سبب الحاجة:** مفتوح المصدر، يدعم العربية والمرادفات والتسامح مع الأخطاء، ويتكامل مع Scout.
- **يتصل بـ:** Laravel Scout، القاموس (synonyms).
- **ما يجب فهمه:** searchableAttributes وترتيبها؛ ranking rules؛ typoTolerance (خطأ لكلمات ≥5 أحرف، خطآن لـ ≥9 افتراضيًا)؛ synonyms (أحادية/متبادلة)؛ matchingStrategy (last)؛ مفتاح الإدارة (master key)؛ المهام غير المتزامنة (tasks).
- **متطلبات تحتاج تحققًا:** الإصدار **[لم يحدده المصدر]**؛ طريقة التشغيل (ملف تنفيذي/Docker) على حاسوب الفريق؛ برنامج تشغيل PHP المطلوب لـ Scout.
- **التحقق:** لوحة Meilisearch أو استعلام مباشر؛ عدد الوثائق في الفهرس = عدد المنتجات المفهرسة.
- **أخطاء شائعة:** نسيان تطبيق الإعدادات بعد تغييرها؛ اختلاف المرادفات المطبّعة عن نص الفهرس؛ «أقل من 50 مللي ثانية» ادعاء المطور لا نتيجة المشروع.

## 6. MySQL 8.4 / Eloquent ORM
- **الدور:** بيانات المتجر المستضيف وجدول `lexicon_entries`؛ استرجاع سجلات النتائج (FR-10).
- **ما يجب فهمه:** العلاقات (belongsTo، belongsToMany عبر جدول وسيط)؛ الترحيلات؛ ترميز utf8mb4 للعربية؛ جلب السجلات بترتيب معرّفات محدد.
- **متطلبات تحتاج تحققًا:** إصدار MySQL الفعلي للمتجر الجاهز؛ ترميز الجداول.
- **أخطاء شائعة:** ظهور العربية كعلامات استفهام بسبب الترميز؛ فقد ترتيب Meilisearch عند جلب السجلات بـ whereIn دون ترتيب.

## 7. Google Chrome
- **الدور:** تشغيل الواجهة واختبارها وبيئة التجارب (حاسوب مكتبي) — القسم 11.3.
- **أخطاء شائعة:** اختلاف السلوك بين Chrome وغيره؛ إعدادات إذن الميكروفون المحفوظة.

## 8. Git / GitHub
- **الدور:** إدارة الشيفرة وتنسيق عمل الفريق.
- **ما يجب فهمه:** الفروع، الالتزامات، طلبات الدمج؛ عدم رفع ملف .env أو مفاتيح Meilisearch.
- **لم يحدد المصدر المعتمد** رابط المستودع ولا سياسة الفروع.

## 9. VS Code / draw.io
- **الدور:** كتابة الشيفرة ورسم المخططات.
