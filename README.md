# منصة التجارة الإلكترونية الداعمة للبحث الصوتي الذكي
### An E-Commerce Platform Supporting Intelligent Arabic Voice Search

مشروع تخرج لنيل درجة البكالوريوس في تقنية المعلومات - جامعة العلوم والتكنولوجيا (فرع إب) - قسم الحاسبات وتكنولوجيا المعلومات (2026-2027م / 1448هـ).

---

## 👥 فريق العمل وإشراف المشروع
* **إعداد الطلاب:**
  1. عبدالرحيم عبدالله عبده علي
  2. عبدالله محمد طاهر الانصاري
  3. بسام عبدالفتاح إسماعيل
  4. زيد رضوان الصلوي
  5. زكريا فيصل العزعزي
* **إشراف:** الدكتور / عصام بهلول

---

## 📌 نبذة عن المشروع
يطور هذا المشروع محرك بحث صوتي ذكي باللغة العربية مخصص لمنصات التجارة الإلكترونية، يتميز بقدرته على:
1. **التعرف الصوتي المباشر:** عبر واجهة `Web Speech API` في المتصفح بنموذج `ar-SA` مع التراجع الآمن للإدخال النصي.
2. **التطبيع الدقيق للنص العربي:** وفق القواعد السبع المعتمدة في استرجاع المعلومات (حذف التشكيل، التطويل، توحيد الألف المهموزة والمقصورة والتاء المربوطة، وتحويل الأرقام).
3. **حذف عبارات الطلب والتأدب:** تصفية عبارات الاستعلام الزائدة ("أبغى"، "لو سمحت"، "هل عندكم"...) دون إفراغ الاستعلام.
4. **القاموس التجاري الموسع (Commercial Lexicon):** استبدال الألفاظ الدارجة والعامية والأجنبية بالمصطلحات المعتمدة للمتجر (Longest n-gram first)، وإدارة المرادفات التكافئية.
5. **محرك الفهرسة والترتيب Meilisearch:** ترتيب النتائج بحسب أوزان الحقول (الاسم > الفئة > الخصائص > الوصف) مع التسامح مع الأخطاء الإملائية.

## 📊 نتائج التقييم والتجارب العملية (الفصل الرابع)
1. **اختبار التكامل الوظيفي:** نجاح 100% لكافة حالات الاختبار العشر (TC-01 إلى TC-10).
2. **التجربة الأولى (دقة التعرف الصوتي WER):** بلغت نسبة الخطأ الإجمالية **4.45%** عبر 400 تسجيل صوتي لخمسة متحدثين بلهجات يمنية وسعودية.
3. **التجربة الثانية (جودة استرجاع البحث):**
   * الدقة عند 5 (P@5): ارتفعت من 0.384 (الخام) إلى **0.896** (+133.3%).
   * متوسط الرتبة العكسية (MRR): ارتفع من 0.442 إلى **0.941** (+112.9%).
   * الاستعلامات الصفرية: انخفضت من 34% إلى **2% فقط**.
4. **التجربة الثالثة (زمن الاستجابة):** بلغ متوسط زمن الاستجابة الكلي **0.452 ثانية**، مطابقاً لمعايير نيلسن لقابلية الاستخدام (< 1.0 ثانية).
