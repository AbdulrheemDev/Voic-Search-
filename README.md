# محرك بحث صوتي ذكي باللغة العربية لمنصات التجارة الإلكترونية

**An E-Commerce Platform Supporting Intelligent Voice Search**

مشروع تخرج — جامعة العلوم والتكنولوجيا، فرع إب، قسم الحاسبات وتكنولوجيا المعلومات، برنامج تقنية معلومات،
العام الجامعي 2026/2027م.

يقدّم هذا المشروع محرك بحث صوتيًا عربيًا **قابلًا للدمج** في منصات التجارة الإلكترونية القائمة، يحوّل الاستعلام
المنطوق إلى نص عبر واجهة التعرف على الكلام في المتصفح (Web Speech API)، ثم يطبّعه ويجرّد منه عبارات الطلب
ويقرّب ألفاظه من مصطلحات المتجر بقاموس تجاري، ثم يبحث به في فهرس Meilisearch عبر Laravel Scout، ويعيد
النتائج مرتبة بحسب الصلة مع بياناتها المحدّثة من قاعدة بيانات المتجر.

## نتائج التجارب المنفذة

**التجربة الثانية — أثر مراحل المعالجة في ملاءمة النتائج (100 استعلام على النصوص المرجعية):**

| الإعداد | الدقة عند 5 | متوسط الرتبة العكسية | الاستعلامات دون نتائج |
| --- | --- | --- | --- |
| (أ) النص كما هو | 0.580 | 0.817 | 9 |
| (ب) + التطبيع وحذف عبارات الطلب | 0.604 | 0.856 | 4 |
| (ج) + القاموس التجاري | **0.720** | **1.000** | **0** |

**التجربة الثالثة — زمن الاستجابة (300 استعلام):**

| الجزء | المتوسط (مللي ثانية) | الوسيط | القيمة العظمى |
| --- | --- | --- | --- |
| المعالجة والتطبيع والقاموس | 0.02 | 0.02 | 0.17 |
| البحث في الفهرس | 2.35 | 2.09 | 16.77 |
| الزمن الكلي في الخادم | 2.38 | 2.13 | 17.08 |
| الزمن الكلي عبر HTTP | 3.82 | 3.44 | 46.40 |

**التجربة الأولى — دقة تحويل الكلام إلى نص:** أداة التسجيل ومواضع إثبات النتائج جاهزة في الوثيقة
(`search:experiment-wer`)، وتُستكمل بعد تسجيل 400 استعلام منطوق (80 استعلامًا × 5 متحدثين).

## التشغيل

```bash
composer install
cp .env.example .env && php artisan key:generate     # ثم ضبط MySQL وMeilisearch في .env
php artisan migrate --seed                           # جداول المتجر وبياناته والقاموس التجاري
php artisan search:index-settings                    # إعدادات الفهرس (الجدول 10.3)
php artisan search:index-products --flush            # فهرسة المنتجات عبر Laravel Scout
php artisan serve                                    # المتجر على /، والبحث على /search
```

### معاينة الواجهات دون تثبيت البيئة

يشمل المشروع خادم معاينة ينفّذ منطق المسار نفسه على البيانات نفسها، لعرض الواجهات وتشغيل التجارب
قبل تثبيت Meilisearch:

```bash
node tools/preview/server.js          # ثم افتح http://localhost:4173
node tools/preview/experiments.mjs reference   # التجربة الثانية (النصوص المرجعية)
node tools/preview/experiments.mjs latency     # التجربة الثالثة (زمن الاستجابة)
node tools/preview/experiments.mjs wer --file storage/app/experiments/recordings_results.csv
```

## المراجع المطابقة

- **الفصل الأول:** الأدوات واللغات (الجدول 2.1)، الأهداف الفرعية الستة، حدود المشروع.
- **الفصل الثاني:** المفاهيم النظرية (التجارة الإلكترونية، البحث الصوتي، التعرف على الكلام، خصائص العربية،
  تطبيع النص، مشكلة المفردات، الفهرس المقلوب، ترتيب النتائج).
- **الفصل الثالث:** الطريقة المقترحة ومكوناتها الخمسة، البيانات، المتطلبات (FR-01…13 وNFR-01…07)،
  المعمارية الطبقية ونقاط التكامل الأربع، الخوارزمية (1.3)، نمذجة البيانات والعمليات، إعدادات الفهرس
  (الجدول 10.3)، وتصميم التجارب ومقاييس التقييم.
