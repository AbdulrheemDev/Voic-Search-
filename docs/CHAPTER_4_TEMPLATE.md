## 1.4 بيئة التنفيذ والتطوير
- **نظام التشغيل وبيئة الخادم:** Windows + Laragon (`PHP 8.3.33`، `MySQL 8.4.3`، `Composer 2.10.2`، `Git 2.47.1`).
- **محرك البحث والفهرسة:** Meilisearch محلي (`http://127.0.0.1:7700`) عبر حزمة `laravel/scout` و`meilisearch/meilisearch-php`.
- **المتصفح المعتمد:** Google Chrome (على حاسوب مكتبي) لدعم `Web Speech API`.
- **المتجر المستضيف:** متجر التطوير المبني بـ Laravel 12 + MySQL (`D-26`)، والتحقق من قابلية الدمج على **Bagisto 2.4** (`D-23`, `D-26`).

## 2.4 تنفيذ حزمة المحرك (`ust/arabic-voice-search`)
نُفّذ المحرك بصيغة حزمة Laravel مستقلة (`Composer Package`) وفق القرار `D-27` عبر نقاط التكامل الأربع المعتمدة:

1. **مكوّن واجهة البحث (`FR-01`, `FR-02`, `FR-03`, `FR-13`, `NFR-04`):**
   - الملفات: `resources/views/components/search-bar.blade.php` و`resources/js/voice-search.js`.
   - يُدمج في أي صفحة بحث بوسم واحد `<x-arabic-voice-search::search-bar />`، مع إخفاء تلقائي لزر الميكروفون في المتصفحات غير الداعمة (`TC-09`) وإظهار حالة الاستماع (`NFR-04`).
2. **مسار واجهة البرمجة (`IR-01`, `IR-06`, `D-30`):**
   - الملفات: `routes/api.php` و`src/Http/Controllers/VoiceSearchController.php`.
   - المسار الافتراضي `GET /api/voice-search?q=...` (قابل للتخصيص من `config/arabic-voice-search.php`) مع الالتزام التام بالخصوصية (`NFR-06`: عدم حفظ الصوت أو نص الاستعلام).
3. **وحدة معالجة النص العربي والقاموس التجاري (`FR-04`, `FR-05`, `FR-06`, `NFR-05`):**
   - `ArabicNormalizer`: القواعد السبع بالترتيب المعتمد في جدول `(7.3)`.
   - `StopPhraseFilter`: عبارات الطلب من جدول `(8.3)` مع شرط عدم إفراغ الاستعلام.
   - `lexicon_entries` (`Migration` + `LexiconEntry`) و`CommercialLexicon`: الجدول الوحيد المضاف لقاعدة البيانات (`NFR-02`)، مع أولوية المطابقة الأطول (كلمتان ثم كلمة).
4. **وحدة الفهرسة والبحث والاسترجاع (`FR-07..FR-12`, `R-08`):**
   - `HasArabicVoiceSearch` Trait: تجميع وتطبيع الحقول الخمسة (`id`, `name`, `category`, `attributes`, `description`).
   - `MeilisearchSettingsBuilder` وأمر `arabic-voice-search:sync-settings`: ضبط `searchableAttributes` و`synonyms` (لمداخل التكافؤ) و`matchingStrategy=last`.
   - `VoiceSearchService`: استرجاع السجلات الحية من MySQL مع الحفاظ الصارم على ترتيب معرّفات Meilisearch.
