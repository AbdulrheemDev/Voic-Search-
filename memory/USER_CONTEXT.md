# سياق المستخدم والفريق (منقول من ذاكرة Claude في claude.ai — 2026-10-23)

> هذا الملف ينقل ما حفظه Claude عن المستخدم والمشروع في claude.ai، لأن Claude Code لا يقرأ تلك الذاكرة. اقرأه بعد CLAUDE.md.

## المستخدم
- الاسم: عبدالله.
- طالب مشروع تخرج (بكالوريوس تقنية المعلومات)، قسم الحاسبات وتكنولوجيا المعلومات، جامعة العلوم والتكنولوجيا – إب، اليمن، العام الجامعي 2026-2027.
- يتواصل بالعربية ويطلب الكتابة بالعربية الأكاديمية الرسمية.

## طريقة العمل المطلوبة
- ردود مختصرة. نفّذ المهمة المطلوبة دون آراء أو نقد غير مطلوب.
- اعمل بدور المشرف خطوة بخطوة؛ لا تُعد فصلًا أو مُخرجًا كاملًا دفعة واحدة.
- في كل خطوة: أدِّ أدوار فريق الطلاب الخمسة (بحث، كتابة، تصميم)، والمشرف (مراجعة)، ولجنة المناقشة (أسئلة متوقعة يُجاب عنها من المشروع)؛ والمستخدم يقرر الصواب قبل الانتقال.
- التقرير يُكتب بوصفه عمل فريق من خمسة طلاب هندسة بحثوا ولخصوا واستنتجوا وصمموا.
- ملاحظات المشرف ودليل المشاريع لهما الأولوية.

## المشروع (كما ذكره المستخدم)
- العنوان المسجل: «منصة للتجارة الإلكترونية تدعم البحث الصوتي الذكي».
- المُخرج المطلوب محرك بحث صوتي عربي، لا منصة كاملة؛ قابل للدمج في متاجر Laravel + MySQL القائمة.
- المسار: Web Speech API ← تطبيع النص وحذف عبارات الطلب ← القاموس التجاري والمرادفات ← Meilisearch عبر Laravel Scout ← MySQL/Eloquent ← عرض النتائج. بلا Intent Detection ولا Entity Extraction ولا LLM ولا Vector Search.
- لا أرقام أداء في التقرير إلا ما قيس فعليًا في الفصل الرابع.
- الدراسات السابقة من 2022–2026.
- الحالة: الفصول 1–3 مكتملة وملاحظات المشرف عليها عولجت؛ الفريق يتحضر للفصل الرابع. ملاحظات لجنة المناقشة يزوّد بها المستخدم إن وردت.
- خطة التنفيذ (2026-10-20): المحرك أولًا حزمةَ Laravel، ثم متجر تطوير خاص لاختباره، ثم التحقق من الدمج في Bagisto 2.4؛ على Windows بـ VS Code وLaragon.
- 2026-10-23: لم يُطبق أي كود؛ ثُبتت البيئة وLaragon فقط. الانتقال إلى Claude Code في VS Code.
